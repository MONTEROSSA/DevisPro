📚 API Endpoints

GET /api/v1/devis/{id}/export

Exportiert fertiges Devis im ERP-nativen Format (Abacus/Proffix/SAP). Permission: devis:read

POST /api/v1/preise/sync

Empfängt Preisliste aus ERP (Artikel, Preise, Rabattgruppen) für DevisPro-Kalkulation. Permission: preise:sync

POST /api/v1/webhook/devis_finalized

Webhook: Wird getriggert wenn Devis in DevisPro finalisiert wird. Permission: webhook

GET /health

Health Check für Monitoring & Load Balancer.

Beispiel: Devis Export (cURL)

# Devis exportieren curl -X GET "https://api.devispro.ch/api/v1/devis/DEV-2026-001/export" \ -H "X-API-Key: dp_abacus_xxx..." # Preise an DevisPro senden curl -X POST "https://api.devispro.ch/api/v1/preise/sync" \ -H "X-API-Key: dp_abacus_xxx..." \ -H "Content-Type: application/json" \ -d '{"artikel": [{"artikelnummer": "A-001", "preis": 85.0, "einheit": "m2", "rabattgruppe": "RG1"}]}'
