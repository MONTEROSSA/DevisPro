# DevisPro - Kunden-Paket (Monterossa AG)

## Installation
1. Doppelklick auf `Installieren.command` (macOS) bzw. `Install_Windows.bat` (Windows).
2. Browser oeffnet sich automatisch auf http://localhost:5070
3. Unter 'Lizenz' den Freischaltcode eingeben (von Monterossa AG erhalten).

## Unterstuetzte Import-Formate
- **SIA-451 / Sorba** (.sia) - CH-Standard
- **Bauweb / Daedalus** (.csv) - CH-Portale
- **Generisches CSV / Excel** (.csv, .xlsx) - eigene Spalten
- **GAEB D84** (DE) (.xml)
- **OENORM B 2063** (AT) (.csv)
- **XRechnung** (EU) (.xml)

Jedes Devis wird automatisch bepreist. Pro Devis: Swiss QR-Rechnung (SPC-0200).
