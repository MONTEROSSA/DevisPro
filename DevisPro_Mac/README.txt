DevisPro - Mac-Version
Ein Produkt der Monterossa AG  -  info@monterossa.ch
=====================================================

INSTALLATION:
1. Diesen Ordner 'DevisPro_Mac' auf Ihren Laptop kopieren.
2. Doppelklick auf 'Installieren.command'.
3. Der Browser oeffnet automatisch: http://localhost:5070

BEI ERSTSTART:
- DevisPro ist gesperrt. Sie erhalten einen Freischaltcode von Monterossa AG.
- Code unter 'Lizenz' eingeben.
- Danach unter 'Stammdaten' Ihre Betriebsdaten + Preise eintragen.

VORABBEDINGUNG: Python 3 (macOS hat es meist schon). Sonst von python.org.
Kein Internet noetig, um DevisPro zu nutzen - alles laeuft lokal.
